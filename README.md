# SaleCentra Windows Screen Lock

A Flutter Windows desktop app that locks a leased computer with a monthly access code system. Works fully offline — no internet required.

## How It Works

- **First code**: lasts **40 days** (grace period)
- **Subsequent codes**: last **30 days** each
- **Disable code**: permanently removes the lock (use when lease is fully paid)
- The app runs at Windows startup, shows a lock screen, and blocks access until a valid code is entered
- Codes are generated by the lessor (you) and shared one at a time after each monthly payment
- The client app does NOT include any code generator — only the lock screen

## What the Locked Screen Shows

When the screen is locked, the user sees:

- A **lock icon** (orange)
- **"SaleCentra Lease"** title
- **"Enter your monthly access code to continue"** subtitle
- A text field with placeholder **"ENTER CODE"**
- An **"Unlock"** button (orange)
- A message area for feedback (e.g., "Invalid code", "Access granted for 40 days")
- **"Code #X required"** at the bottom — indicates which code number is expected

The window stays **always-on-top** and **cannot be closed** while locked.

When unlocked, the app minimizes and shows days remaining.

## Setup

### 1. Install Flutter Windows support

```powershell
flutter config --enable-windows-desktop
```

### 2. Build the app

```powershell
cd C:\Users\efosa\OneDrive\Desktop\SaleCentra_APP\Flutter\salecentra_lock
flutter build windows --release
```

The built app will be in `build\windows\x64\runner\Release\`.

### 3. Deploy to the leased computer

1. Copy the entire `Release` folder to the leased computer (e.g., `C:\SaleCentraLock\`)
2. Run the app once (`salecentra_lock.exe`) — it will:
   - Automatically register itself in the Windows registry to start at every boot
   - Lock immediately and wait for the first access code
3. No manual startup setup needed — the app handles it automatically

The app writes to `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` so it launches at every boot. If registry access fails, it falls back to creating a batch file in the Windows Startup folder.

### 4. Using the codes

- **Month 1**: Share Code #1 (40 days) after receiving first payment
- **Month 2**: Share Code #2 (30 days) after receiving second payment
- **Month 3+**: Continue sharing the next code each month
- **Final**: Share the disable code when all payments are complete

## Security Notes

- The state file is stored in the app support directory
- Codes are generated using SHA-256 with a secret salt
- The app prevents window closing when locked (always-on-top)
- No internet connection required — fully offline operation

## Customization

- Change the secret salt in `lib/code_manager.dart` (`_secretSalt`)
- Change the disable code in `lib/code_manager.dart` (`_disableCode`)
- Change durations in `getDurationDays()`
